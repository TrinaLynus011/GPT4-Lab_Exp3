
# Experiment 3 – Intelligent Email Assistant

## Aim
To build an intelligent email assistant that uses a stored FAQ
knowledge base and Ollama LLM to draft professional email replies.

## Technologies
- Python
- Ollama
- Qwen 2.5 (0.5B)
- Requests

## Features
1. FAQ keyword matching
2. AI-generated email replies
3. Conversation history
4. Interactive email input

## Execution

Install dependencies:

    python -m pip install -r requirements.txt

Download the model:

    ollama pull qwen2.5:0.5b

Run the program:

    python app.py

Type exit to stop the application.
